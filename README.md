# pi-agent-skills

Source-managed Pi package for Mitch's reusable agent workflows.

- `ask-clarifying-questions`
- `bro`
- `deslop`
- `diagram-creation`
- `dogfood`
- `handoff`
- `pi-extension-development`
- `propose-then-ship-pi`
- `tdd`
- `thermo-nuclear-code-quality-review`
- `verification-before-completion`

## Install

```bash
pi install git:github.com/fitchmultz/pi-agent-skills
```

## Validate

```bash
npm test
npm run smoke
npm run pack:check
```

This repository is private to npm publishing. Install it from git or a local checkout.
