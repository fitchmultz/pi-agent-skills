# pi-agent-skills

Source-managed Pi package for Mitch's delivery, verification, review, and technical-diagram skills.

## Skills

- `propose-then-ship-pi`
- `verification-before-completion`
- `deslop`
- `thermo-nuclear-code-quality-review`
- `diagram-creation`

## Install

```bash
pi install git:github.com/fitchmultz/pi-agent-skills
```

## Validate

```bash
npm test
npm run smoke
npm run pack:check
```

This repository is private to npm publishing. Install it from git or a local checkout.
