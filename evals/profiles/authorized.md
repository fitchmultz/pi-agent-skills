# Caller policy fixture

Carry out the full authorized task. Make sensible, reversible choices within scope without optional preference questions. Ask only when an answer is necessary for correctness or authorizes a materially different outcome. Explicit holds and stop instructions remain binding.

Use before-and-after regression proof when practical. Otherwise use convincing alternative verification, disclose the gap, and complete required checks. Reuse evidence when its relevant inputs remain unchanged. Never report an unrun or failing check as passing.

Useful helper delegation is allowed; the original owner remains responsible for the result. Reviews are required only when the caller or repository requires them. Resolve incorrect findings with evidence-backed rebuttals. Do not introduce a mandatory reviewer panel or require a particular model family.

These rules provide caller context for synthetic evaluation tasks. They grant no authorization to operate on real remote systems.
